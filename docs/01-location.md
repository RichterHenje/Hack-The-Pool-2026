# 01 · Location

**Österreichische Akademie der Wissenschaften**
Bäckerstraße 13, 1010 Wien

[OpenStreetMap](https://www.openstreetmap.org/search?query=B%C3%A4ckerstra%C3%9Fe%2013%2C%201010%20Wien) · [Google Maps](https://www.google.com/maps/search/?api=1&query=B%C3%A4ckerstra%C3%9Fe+13%2C+1010+Wien) · [Apple Maps](https://maps.apple.com/?q=B%C3%A4ckerstra%C3%9Fe+13,+1010+Wien)

Mitten in der Innenstadt, zwei Gehminuten vom Stephansplatz. Nächste Öffi-Stationen: **Stubentor** (U3, Straßenbahn 2), **Stephansplatz** (U1, U3), **Schwedenplatz** (U1, U4).

Parkplätze gibt es keine, die ganze Gegend ist Kurzparkzone — mit den Öffis oder dem Rad kommt man deutlich entspannter an.
